## Findings

**C1 · Inputs wider than their digits (the user's 18, measured).** Stroke › Weight: `0` + *pt* in a **153px** input (`color/StrokePanel` — the Input fills the row, no `chars`). The Colour panel's Opacity: `100` in 48px — fine. The inspector's Transform fields: `0` in a **140px** property field (X · Y · rotation · opacity) and `1080` in 123px — the DS `Input variant="property"` on a two-column grid, so the width is the grid's, not the value's. The labs/Parameters rail: `1.10` in 41px — right. *Fix the Stroke weight (a `chars` width); ruling on the property grid — a half-width field for a one-digit value is the DS's own rule, change it there or accept it.*

**C2 · The File footer tab is the File menu again.** Footer › File holds Save… · Save as… · Files… — the same three verbs the top File menu holds — plus Save to file / Load from file and the Audio strip. Two homes for one verb set; the menu is the DS idiom. `shell/panels/EditorFooter.jsx`. *ruling: the footer keeps what the menu does not have (file import/export · audio), the verbs leave.*

**C3 · "Add effect" adds nothing.** Effects tab, press *Add effect*: a stage appears as Type *Halftone* · Category *None* — an effect row that does nothing until a category is picked, with no cue that it is incomplete. `inspectors/EffectsPanel.jsx` — the stage's default. *fix: default to the type's first real category, or make the picker one step.*

**C4 · The binding path is invisible by default.** *Modulation dots* is off in Settings, so no parameter row shows a bind dot and the Animation tab's modulation editor has nothing to open from; the only way in is the `M` key or the setting. `settings/AppSettings.jsx` default. *ruling: on by default, or a visible "Modulate…" entry per row.*

**C5 · The Parameters tab empty state** (`Select a layer to edit its parameters.`) and the Effects tab's wear `kol-helper-12` through the `Hint` wrapper — pass D carries the sweep (the user's 19).

Clean: every popover clamps inside the viewport (the family list scrolls at 268px); the Transform strip's align/flip/rotate cells and the Appearance eye/drop are DS `Button`s; the labs rail's inputs are `chars`-sized; the Output tab's export controls read as one set.
