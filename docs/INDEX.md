# Docs

The documentation vault for **kol-fxr**. Two homes here:

- [[documentation/INDEX|documentation]] — **the subject**: the app's systems in numbered sections (00–10).
- [[operations/INDEX|operations]] — **repo machinery**: build, deploy, and packaging process.

Agent state (architecture, current context, session logs, decision history) lives outside this vault in `.kol/llm-context/`; the doc spec these files conform to lives in `.kol/docs-framework/`. See the root `LLM_RULES.md` for the where-things-live map.
